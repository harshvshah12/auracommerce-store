# AuraCommerce Hardware Store

> Precision-machined hardware gear for developers & creators

Built autonomously from voice requirements using **[VoxBuild AI](https://voxbuild.ai)**.

## Architecture
- **Framework**: Next.js 15 (App Router) & React 19
- **Archetype**: ECOMMERCE
- **Styling**: Tailwind CSS (Minimalist Tech Store with Emerald Accents)
- **Backend**: Ready for Supabase PostgreSQL
- **Deployed on**: Vercel Global Edge Network

## Getting Started
```bash
npm install
npm run dev
```
